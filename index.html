01 · Problem

도입 결정은 내려졌는데, 실행이 안 됩니다.

기업 AI 과제가 멈추는 원인은 대개 세 가지로 반복됩니다.

  • 인력

    LLM·에이전트를 만들고 운영해 본 사람이 사내에 없습니다. 채용은 느리고 비쌉니다.

  • 기술

    파싱·임베딩·학습·서빙·평가를 전부 직접 조립해야 합니다. 조립하는 사이 모델과 도구가 바뀌고, 바꿀 때마다 다시 조립해야 합니다.

  • 데이터

    HWP·스캔 PDF·사내 시스템에 흩어진 자료는 그대로는 AI가 읽지 못합니다. 권한 체계는 더 복잡합니다.

02 · Why Toaster

끝난 뒤에도 고객에게 남는 것이 다릅니다.

과제마다 처음부터 짓는 외주 구축과, 제품 위에서 쌓아 가는 방식의 차이입니다.

항목SI · 외주 구축Toaster
자산과제별 납품 코드로 남습니다.데이터·모델·에이전트·평가셋이 제품 안에 남습니다.
재사용다음 과제는 다시 처음부터 시작합니다.같은 검색 자산과 모델로 두 번째, 세 번째 에이전트를 만듭니다.
검증납품 시점의 인수 테스트가 중심입니다.버전마다 품질·보안·회귀를 같은 기준으로 측정합니다.
운영유지보수 계약 범위 안에서 수정합니다.현업과 IT가 UI에서 직접 고치고 다시 배포합니다.

SI를 대체하지 않습니다. SI 파트너가 Toaster 위에서 지으면 양쪽 모두 빨라집니다.

03 · Toaster Platform

만들고, 검증하고, 운영합니다. 고객 환경 안에서.

Toaster는 두 라인, 다섯 제품으로 이루어져 있습니다. 필요한 제품부터 따로 도입할 수 있습니다.

MODEL LINE

자체 도메인 모델을 만듭니다

Studio Forge Judge
  • Studio문서에서 학습 데이터를 만들고, 사람이 승인한 것만 학습에 씁니다.
  • Forge업무에 맞게 학습하고, 양자화해 바로 서빙합니다.
  • Judge답변의 품질과 보안을 버전마다 같은 기준으로 측정합니다.

AGENT LINE

그 모델로 에이전트를 만듭니다

Index Agent
  • IndexHWP·스캔 PDF·음성·영상까지 파싱해 검색 자산으로 만듭니다.
  • Agent현업이 UI에서 에이전트를 만들고, 조직 권한 안에서 실행합니다.

두 라인 모두 온프레미스·폐쇄망(망분리 포함) 환경에 설치되며, 데이터·모델·에이전트는 전부 고객 자산으로 남습니다.

04 · Security

보안과 규제 준수는 옵션이 아니라 기본값입니다.

  • 프라이빗 배포

    온프레미스·폐쇄망(망분리 포함) 환경에 설치합니다. 학습과 서빙, 평가까지 외부 API 없이도 고객 GPU에서 처리할 수 있으며, 외부 모델 API를 쓸지는 고객이 정합니다.

  • 권한 선검증

    조직도·권한 시스템을 연동해 권한을 가장 먼저 확인합니다. 연동하면 열람 권한이 없는 자료는 검색 대상에서 빠집니다.

  • 입력 보안 체크

    개인정보 포함, 프롬프트 인젝션, 금지 주제, 업무 범위 이탈 여부를 먼저 판단하고, 위반 유형별로 정해 둔 응답으로 대체합니다.

  • 배포 전 보안 점검

    인젝션·탈옥·시스템 프롬프트 유출을 측정합니다. 치명적인 공격이 한 건이라도 통하면 그 버전은 배포하지 않습니다.

05 · How to start

작게 시작해 자산으로 남깁니다.

  1. 01

    PoC

    업무 하나와 고객 데이터 일부로 시작합니다. 플랫폼을 설치하고 에이전트 한 건을 만들어 평가 리포트로 확인합니다.

    결과 정량 지표, 확장 범위 제안

  2. 02

    구축

    사내 자료를 검색 자산으로 만들고 권한을 연동해 업무별 에이전트를 늘립니다. 필요하면 도메인 모델도 학습합니다.

    결과 운영 가능한 플랫폼, 운영 매뉴얼

  3. 03

    운영

    현업이 에이전트를 직접 추가하고 고칩니다. 운영 로그는 비식별 처리하고, 고객이 승인한 범위만 다음 학습 데이터로 씁니다.

    결과 고객이 소유한 데이터·모델·에이전트

기존 SI 파트너가 있다면 그 파트너가 Toaster 위에서 구축합니다. 벤더를 바꾸지 않아도 됩니다.

업무 하나로 시작하는 PoC를 제안합니다.

대상 업무와 데이터 환경을 알려주시면 범위와 확인할 항목을 정리해 회신합니다.
